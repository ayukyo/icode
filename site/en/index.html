Get started

Run ICODE locally

All you need is Python 3.11+. Complete one automatic check after installation, then open the local workbench.

terminal
# 1. Install ICODE Agent
python -m pip install icode-agent

# 2. Complete the one-time setup
icode setup

# 3. Check protection and model settings
icode doctor

# 4. Open the local workbench
icode workbench
01

Run the check first

doctor explains what this computer supports and whether anything needs attention.

02

Connect a model next

A model account or key is needed only when you start real task work. Basic checks remain offline.

03

Open the workbench

Create tickets, follow progress, and respond when a task needs your decision.

Runtime protection

How ICODE protects your project

Keep work in scope

File and command operations stay within the folders and steps allowed for the current task.

Ask before important actions

Network access, package installation, and other high-impact actions explain their purpose first.

Cross-platform runtime protection

Uses the matching system capabilities on Linux, macOS, and Windows to limit files, network connections, and processes.

The website cannot read tickets

This is a static site with no login, analytics, tracking, or connection to your local workbench.
