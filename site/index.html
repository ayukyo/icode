从需求到交付

你只需要说明要做什么

ICODE Agent 负责推进任务；ICODE-SKILL 提供经过约定的研发步骤和检查要求。两者分工明确，用户不需要理解内部术语。

开始使用

先在本地运行起来

只需要 Python 3.11+。安装后完成一次自动检查，即可打开本地工作台。

terminal
# 1. 安装 ICODE Agent
python -m pip install icode-agent

# 2. 完成首次运行设置
icode setup

# 3. 检查运行保护和模型配置
icode doctor

# 4. 打开本地工作台
icode workbench
01

先运行检查

doctor 会告诉你当前电脑支持哪些功能，以及需要处理什么。

02

再配置模型

只有真正开始处理任务时才需要模型账号或密钥，基础检查可以离线完成。

03

最后打开工作台

在浏览器中创建工单、查看进度，并处理需要你确认的事项。

运行保护

ICODE 如何保护你的工程

限定工作范围

文件和命令操作只在当前任务允许的目录和步骤中进行。

重要操作先确认

联网、安装依赖和其他高影响动作会单独说明用途并请求确认。

跨平台运行保护

在 Linux、macOS 和 Windows 上使用对应的系统能力限制文件、网络和进程范围。

官网不读取工单

本站是静态页面，无登录、统计或跟踪功能，也不会连接你的本地工作台。
