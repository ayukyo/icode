同一套 ICODE 品牌，两种独立职责

ICODE-SKILL 规定“什么算对”，ICODE Agent 负责“怎样做到”。本仓只读消费固定版本的控制平面，不复制状态机，也不调用另一个宿主 Agent 代替执行。

离线先行

四步完成本地自检

需要 Git 和 Python 3.11+。离线自检不需要模型密钥；HTTPS 子模块地址让公开仓库可以直接递归克隆。

terminal
# 1. 克隆 Agent 与固定版本控制平面
git clone --recurse-submodules https://github.com/ayukyo/icode.git
cd icode

# 2. 创建隔离的 Python 环境
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .

# 3. 核对契约、Guard 与隔离能力
icode doctor

# 4. 在一次性目录跑离线握手
mkdir -p /tmp/icode-handshake
icode handshake --workspace /tmp/icode-handshake
01

先看能力事实

doctor 会区分“探测到后端”和“真正可用”，不会把应用层 Guard 说成沙箱。

02

再接模型端点

真模型命令才需要端点与仓外密钥。离线合同与证据校验保持零成本。

03

最后以退出码验收

模型的总结不是完成判据；独立测试、控制面门禁和验证回执才是。

诚实边界

证据能证明什么，不能证明什么

能证明

记录自洽、产物正文与链上哈希对应，并能检测覆盖范围内的篡改。

不能证明

代码绝对正确、设备真实运行、部署版本一致，或未锚定证据包具备抗抵赖性。

隔离事实

有内核/容器后端时报告实际强制项；没有时明确标注“应用层限制，非沙箱”。

官网隐私

本站为静态文件，无登录、脚本、分析、跟踪器，不连接本地工作台或读取工单。
